## 🇬🇧 English

### About The Repository

This repository contains my progress, hands-on practices, and projects created while re-processing the **Fullstack Web Development** course, fully updated with **ASP.NET 9** and **React 19**. After completing my military service, I initiated this structured roadmap to refresh, consolidate, and elevate my technical skills with a disciplined daily workflow.

### 📁 Repository Structure

- `01-html-css/` - Fundamentals of web structuring and styling.
- `02-bootstrap/` - Responsive web design with Bootstrap components & grid system.
- `03-javascript/` - Modern ES6+ JavaScript, DOM manipulation, and async programming.
- `04-react/` - Modern UI development with React 19, components, hooks, and state management.
- `05-aspnet-core-api/` - Backend development with ASP.NET 9, Web API, EF Core, and architecture patterns.
- `06-fullstack-projects/` - End-to-end fullstack applications combining frontend & backend.

### 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript (ES6+), React 19
- **Backend:** C#, ASP.NET 9 Core MVC / Web API, Entity Framework Core
- **Database:** SQL Server
- **Tools:** VS Code, Git, GitHub
